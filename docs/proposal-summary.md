# 다왔어? (Are We There?) — 기획 요약

## 한 줄 소개
아이가 "다 왔어?"라고 묻기 전에, 내비의 남은 거리·시간에 맞춰 이야기와 퀴즈가 이어지고 도착하는 순간 결말이 나는 뒷좌석 음성 동행 앱.

## 기획 배경
- 주말 장거리(서울·경기 → 강원 1.5~3시간)에서 5~9세 아이는 수십 번 "언제 도착해?"를 묻는다. 아이는 '40분'을 체감하지 못한다.
- 태블릿 영상은 멀미·화면 시간 걱정이 있고, 동요·오디오북은 여행과 상관없이 끝나 도착 직전에 끊기거나 너무 일찍 끝난다.
- 차는 목적지·남은 시간·정체·휴게소 경유를 이미 안다. 이 정보를 아이가 알아듣는 말로 바꿔 주는 앱이 없다.
- 국내여행 교통수단의 84.5%가 자동차(2025 국민여행조사).

## 주요 기능 · 차량 특화 요소
1. **도착에 맞춰 끝나는 이야기** — 남은 시간·교통 정보로 편수·길이를 정하고 도착 2~3분 전에 결말. 막히면 보너스 장, 뚫리면 줄임.
2. **남은 시간을 아이 단위로** — "이야기 두 편 남았어", "퀴즈 다섯 개 풀면 바다야". "다 왔어?"에 음성으로 바로 답.
3. **아이 이름으로 이어지는 시리즈** — 지난 여행에서 끝난 장면을 기억해 다음 여행에서 이어 감(정보는 차량 안에만 저장).
4. **음성 퀴즈 · 형제 차례 놀이** — 말로 답하면 음성 인식으로 채점, 경로의 터널·강·휴게소를 퀴즈 재료로.
5. **운전 상황에 맞춘 안전 설계** — 주행 중엔 음성만, 화면은 정차 때만. 길 안내 음성 직전 일시정지, 휴게소에서 문이 열리면 멈춤 → 출발하면 한 줄 요약으로 재개. 운전자가 만질 일 없음.
6. **산간·터널에서도 끊기지 않음** — 이야기는 출발 전에 묶음으로 받아 두고, TTS 는 통신이 끊기면 차량 내장 엔진으로.

## 사용 시나리오 (서울 마포 → 속초, 7세·5세 남매, 예시 인물)
출발 전(정차) "2시간 40분 = 이야기 4편·퀴즈 12개" → 주행 중 진행 막대 + 음성 → 정체 +20분 보너스 장, "다 왔어?" → "이야기 두 편 반 남았어" → 휴게소 문 열림 멈춤·점수판 → 도착 3분 전 결말, "도착! 하은 9개, 지호 7개", 다음 편 예고.

## 개발 계획
- Pleos Connect(Android Automotive OS) 앱, Kotlin, Pleos Connect Emulator(API 34 automotive)에서 개발·시연.
- SDK: NaviHelper(목적지·경로·주행 상태·경유지/목적지 도착·TBT·정체), TextToSpeech(HYBRID), SpeechToText, Vehicle(주차 브레이크·주행 모드·문 상태, Capability API 로 지원 여부 확인), FusedLocation(경로 위 퀴즈 재료), Gleo 음성 비서 연동(가이드 확인 후).
- 콘텐츠는 생성형 AI 로 미리 만들고 사람이 아동 적합성을 검수한 묶음만 사용 — 주행 중 실시간 생성 없음.
- 개인정보: 아이 이름·나이·진행 기록은 차량 안에만, 음성 원문은 서버에 저장하지 않음.

## 기대효과
- 타깃: 5~9세 자녀와 주말 1시간 이상 이동하는 가족(첫 시장: 서울·경기 → 강원).
- 수익 모델(가설): 기본 무료 + 가족 구독, 이후 휴게소·관광지·지자체 제휴 퀴즈 묶음.
- MAU·리텐션 수치는 가정이며 사전 신청 페이지(https://www.worldwidesomething.com/ko/are-we-there)로 수요를 검증 중.
